# Tiny Worlds

Fifty tiny interactive worlds — each a cutaway diorama with one atmosphere and one satisfying touch. Built with [Three.js](https://threejs.org/) (MIT), no build step: every world is a single static page.

**Live:** https://designbysomil.github.io/tiny-worlds/

Each world lives in its own folder and is served at `/tiny-worlds/<name>/`. Open source under MIT — fork it, learn from it, build your own.

Batch 1 (live): Volcano island · Mushroom night forest · Thunderstorm cell · Lighthouse at night · Steam train loop
